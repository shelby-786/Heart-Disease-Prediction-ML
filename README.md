# Heart Disease Prediction Using Machine Learning

## Project Overview
This project focuses on predicting heart disease using machine learning classification algorithms. The dataset contains 270 patient records with 13 input features.

## Algorithms Used
- Logistic Regression
- Decision Tree
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Random Forest
- Gradient Boosting
- AdaBoost

## Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Jupyter Notebook

## Results
Logistic Regression and Naive Bayes achieved the highest accuracy of 85.19%. Logistic Regression achieved 91.67% recall and was selected as the best overall model in this experiment.

## Purpose
To understand the classification workflow, model training, evaluation, and comparison of machine learning algorithms.

*This project is for educational purposes only and is not intended for medical diagnosis.*
